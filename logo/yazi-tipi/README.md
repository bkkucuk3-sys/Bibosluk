# biboşluk yazı tipi

Logoda kullanılan yazı tipi: **Montserrat Extra Bold Italic** (Julieta Ulanovsky ve ekibi, SIL Open Font License 1.1 — ticari kullanım ve dağıtım serbest).

- Dosya: `Montserrat-Italic-VariableFont_wght.ttf` (değişken font)
- Kalınlık (`wght`): **800** (Extra Bold)
- Yazım: küçük harf, **biboşluk**
- Harf aralığı: +2 birim (logoda 96 punto boyutunda)
- Renk: lacivert `#042455`
- Özel ayrıntılar:
  - "i" harfinin noktası harfin kendisi yerine sarı daire (`#FAAD07`), yarıçap = punto × 0,10.
  - Harflerin içinden, x-yüksekliğinin %42'sinde, ince bir dalga çizgisi geçer (zemin rengiyle kesilmiş). Kalınlık = punto × 0,04.
- `biboşluk-yazi.svg`: yazının tek başına, çizgiye çevrilmiş hali.
- Orijinal kaynak: https://fonts.google.com/specimen/Montserrat
